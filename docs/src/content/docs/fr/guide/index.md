title: "Apprendre Outpost"
description: "Un parcours progressif du premier agent aux workflows durables."
---

Suivez ce parcours dans l’ordre ou ouvrez directement une page pratique. Sa préparation recrée tout ce dont l’exemple a besoin.

1. [Démarrer un agent](start/quickstart/) : choisir son accès, lancer le starter CLI et examiner le résultat.
2. [Comprendre le code généré](start/generated-script/) : identifier dépôt, agent, provider et brief.
3. [Piloter la tâche](agents/dispatch/) : prompts, réponses validées, progression et conversations.
4. [Maîtriser l’environnement](environment/lifecycle/) : durée de vie, workspaces, Git et commandes.
5. [Composer un workflow](workflows/graph/) : résultats typés, dépendances et politiques d’échec.
6. [Conserver l’état](advanced/checkpoints/) : persistance, décisions, artefacts et workers.
7. [Combiner les éléments](cookbook/) : recettes complètes pour des usages concrets.
8. [Récupérer délibérément](operations/troubleshooting/) : diagnostics et travail conservé.

La [Référence](../reference/) contient les contrats exhaustifs, options et compatibilités. Elle se consulte à la demande.
