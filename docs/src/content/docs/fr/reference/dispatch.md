## Import

```ts
import { dispatch } from "@elie-laloum/outpost";
```

## Rôle et comportement

Exécute un brief dans une sandbox allouée pour cet appel, intègre la branche en cas de succès, puis ferme la sandbox. En cas d’échec, la sandbox est fermée, le worktree est conservé et le recovery de l’erreur indique la branche et le répertoire. Avec passes supérieur à 1, chaque passe est un dispatch distinct qui s’arrête dès qu’un marqueur de fin apparaît. Le garde-fou du workspace s’exécute après synchronisation et avant intégration ; son refus est un échec qui conserve le worktree.

[Exemple complet et règles détaillées](../../guide/first-request/).
