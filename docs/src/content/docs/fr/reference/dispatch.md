## Import

```ts
import { dispatch } from "@elie-laloum/outpost";
```

## Rôle et comportement

Exécute un brief dans une sandbox allouée pour cet appel, applique la politique du workspace puis ferme la sandbox. En mode Git, le défaut est current pour une exécution montée et integrate pour une exécution distante ; named conserve la branche sans fusion. Les workspaces de fichiers suivent leurs politiques de conservation et de publication. En cas d’échec, les détails de récupération désignent le travail conservé. Avec plusieurs passes, l’exécution s’arrête lorsqu’un marqueur de fin apparaît. Un garde-fou vérifie le diff commité après synchronisation et avant intégration ; le travail refusé est conservé.

[Exemple complet et règles détaillées](../../guide/first-request/).
