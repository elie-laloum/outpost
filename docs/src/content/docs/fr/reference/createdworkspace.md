## Import

```ts
import type { CreatedWorkspace } from "@elie-laloum/outpost";
```

## Paramètres et propriétés

Les champs ci-dessous couvrent toutes les variantes ; la signature précise leurs combinaisons autorisées.

| Nom                     | Type                                                                                                                                                                                                                                                                                                                                                      | Présence          | Rôle                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| ----------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `kind`                  | `"ephemeral" \| "directory" \| "git"`                                                                                                                                                                                                                                                                                                                     | Requis            | Discriminant sélectionnant Git, une source dossier ou un workspace initialement vide.                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `source`                | `FileWorkspaceSource`                                                                                                                                                                                                                                                                                                                                     | Selon la variante | Source déclarée pour une ressource possédée ; exclusive de l’emprunt d’un workspace ouvert.                                                                                                                                                                                                                                                                                                                                                                                                              |
| `checkpoint`            | `() => Promise<FileWorkspaceRecord>`                                                                                                                                                                                                                                                                                                                      | Selon la variante | Synchronise et vérifie une génération settled avant de renvoyer sa description durable ; refuse les opérations actives.                                                                                                                                                                                                                                                                                                                                                                                  |
| `sandbox`               | `(options: FileSandboxSettings) => Promise<FileSandbox> \| (options?: Omit<SandboxOptions, Exclude<keyof WorkspaceOptions, "hooks" \| "label"> \| "workspace">) => Promise<Sandbox>`                                                                                                                                                                      | Requis            | Sandbox liée à ce workspace ; sa fermeture laisse ouvert un workspace emprunté.                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `dispatch`              | `<T = undefined>(options: FileSandboxSettings & DispatchOptions<T> & { readonly agent: DispatchAgent; }) => Promise<FileDispatchResult<T>> \| <T = undefined>(options: Omit<SandboxOptions, Exclude<keyof WorkspaceOptions, "hooks" \| "label"> \| "workspace"> & DispatchOptions<T> & { readonly agent: DispatchAgent; }) => Promise<DispatchResult<T>>` | Requis            | Exécute un agent sur les fichiers actuels, en conservant le workspace entre réparations et passes de steering.                                                                                                                                                                                                                                                                                                                                                                                           |
| `id`                    | `string`                                                                                                                                                                                                                                                                                                                                                  | Requis            | Identifiant stable de cette ressource, indépendant du chemin de matérialisation.                                                                                                                                                                                                                                                                                                                                                                                                                         |
| `directory`             | `string`                                                                                                                                                                                                                                                                                                                                                  | Requis            | Répertoire local absolu de matérialisation ou de source ; ce chemin n’est pas une identité portable.                                                                                                                                                                                                                                                                                                                                                                                                     |
| `runtime`               | `WorkspaceRuntime`                                                                                                                                                                                                                                                                                                                                        | Requis            | Répertoire de contrôle et namespace logique, séparés des fichiers du workspace.                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `close`                 | `(options?: { readonly preserve?: boolean; }) => Promise<Disposal>`                                                                                                                                                                                                                                                                                       | Requis            | Fermeture idempotente ; conserve le travail récupérable et ne supprime jamais une source empruntée.                                                                                                                                                                                                                                                                                                                                                                                                      |
| `[Symbol.asyncDispose]` | `() => Promise<void>`                                                                                                                                                                                                                                                                                                                                     | Selon la variante | Fermeture idempotente ; conserve le travail récupérable et ne supprime jamais une source empruntée.                                                                                                                                                                                                                                                                                                                                                                                                      |
| `git`                   | `Workspace`                                                                                                                                                                                                                                                                                                                                               | Selon la variante | Capacité Git legacy dédiée, exposant branches, commits, guards et intégration.                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `attach`                | `(options: Omit<SandboxOptions, Exclude<keyof WorkspaceOptions, "hooks" \| "label"> \| "workspace"> & AttachOptions & { readonly agent: Agent; }) => Promise<AttachResult>`                                                                                                                                                                               | Selon la variante | Ouvre le terminal interactif d’un agent dans une nouvelle sandbox sur ce workspace. Si le terminal sort avec le statut 0, il fusionne une branche integrate ; la sandbox est fermée et le workspace reste ouvert.                                                                                                                                                                                                                                                                                        |
| `integrate`             | `{ (): Promise<void>; (options: IntegrationOptions): Promise<ConflictResolution \| void>; }`                                                                                                                                                                                                                                                              | Selon la variante | Fusionne la branche de travail uniquement en mode integrate. Sans onConflict, utilise la fusion directe habituelle sur l’hôte et ne renvoie aucune valeur. Avec onConflict, exige une sandbox fermée, précontrôle les commits figés, appelle la stratégie seulement pour un véritable conflit Git, vérifie ascendance et guard finaux puis intègre le commit exact vérifié. Renvoie ConflictResolution lorsque la stratégie s’est exécutée ; les refus conservent les worktrees source et de résolution. |
| `repository`            | `string`                                                                                                                                                                                                                                                                                                                                                  | Selon la variante | Chemin réel du répertoire racine du checkout hôte.                                                                                                                                                                                                                                                                                                                                                                                                                                                       |

| `baseBranch`            | `string`                                                                                                                                                                                                                                                                                                                                                  | Selon la variante | Branche extraite dans le checkout hôte à l’ouverture du workspace, et cible de integrate(). | `baseline`              | `string`                                                                                                                                                                                                                                                                                                                                                  | Selon la variante | Commit extrait dans le workspace à son ouverture. Chaque dispatch liste les commits depuis son propre commit de départ, pas depuis celui-ci.                                                                                                                                                                                                                                                                                                                                                             |
| `gitDirectories`        | `readonly string[]`                                                                                                                                                                                                                                                                                                                                       | Selon la variante | Chemins hôtes du dossier Git du worktree et du dossier Git commun du dépôt. Les providers de conteneurs les montent, sauf si repositoryMode vaut isolated.                                                                                                                                                                                                                                                                                                                                               |
| `policy`                | `BranchPolicy`                                                                                                                                                                                                                                                                                                                                            | Selon la variante | Politique de branche appliquée, { mode: "current" } si aucune n’a été fournie.                                                                                                                                                                                                                                                                                                                                                                                                                           |
