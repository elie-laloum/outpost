## Import

```ts
import { createVercelSandboxProvider } from "@elie-laloum/outpost/providers/vercel";
```

## Rôle et comportement

Crée un provider distant sur Vercel Sandbox ; le SDK optionnel @vercel/sandbox se charge à l’acquisition. Chaque acquire crée une sandbox, Outpost y envoie le dépôt puis resynchronise les changements, et release arrête la sandbox.

[Exemple complet et règles détaillées](../../guide/cloud-sandboxes/).
