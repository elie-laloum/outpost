## Import

```ts
import { inspectExecution } from "@elie-laloum/outpost/core";
```

## Rôle et comportement

Planifie une exécution à partir des options de sandbox sans allouer, transférer de fichiers ni démarrer d’agent. Pour un workspace de fichiers, elle indique le mode de liaison requis par la source, ce que propose le fournisseur de sandbox, les capacités fichiers déclarées par chaque agent, les exigences des réglages de dispatch facultatifs et chaque incompatibilité ; createSandbox() et dispatch() refusent le premier diagnostic avec le même message. Les options Git renvoient la sandbox et les agents sans exigence fichiers. Les fournisseurs d’extension sont lus depuis leurs capacités d’exécution.

[Exemple complet et règles détaillées](../../guide/sandbox-sessions/).
