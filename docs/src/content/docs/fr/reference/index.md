---
title: "Référence"
description: "Chaque contrat public d’Outpost, regroupé en familles. Ouvrez la vue d’ensemble d’une famille pour ses concepts, ou allez directement à une fonction, un type ou une interface."
---

Chaque page documente un symbole public : son import, son comportement, ses paramètres et propriétés, sa valeur de retour et sa signature, générés à partir des déclarations de types du package. Les familles regroupent les symboles liés ; chacune commence par une vue d’ensemble qui renvoie vers son guide pratique.
