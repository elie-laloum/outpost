## Import

```ts
import { createSandbox } from "@elie-laloum/outpost";
```

## Rôle et comportement

Alloue un environnement avec sandboxProvider et le garde ouvert pour enchaîner dispatchs, commandes et sessions de terminal jusqu’à ce que vous le fermiez. Sans workspace, elle en ouvre un que close() ferme aussi, par défaut sur le checkout du répertoire courant avec Docker. Si la préparation échoue, elle libère ce qu’elle a alloué, ferme le workspace qu’elle a ouvert et relance l’erreur.

[Exemple complet et règles détaillées](../../guide/sandbox-sessions/).
