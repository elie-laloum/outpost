## Import

```ts
import { attach } from "@elie-laloum/outpost";
```

## Rôle et comportement

Ouvre le terminal interactif de la CLI d’un agent dans une sandbox allouée pour cet appel, puis renvoie le statut de sortie et les commits de la session. Le statut 0 applique la politique de branche et ferme la sandbox ; un statut non nul ou un échec la ferme et conserve le worktree. Le processus de l’agent a un délai de 86400000 (24 heures). Le statut 0 vérifie aussi le garde-fou de diff du workspace avant intégration ; un diff refusé lève le code guard et conserve le travail.

[Exemple complet et règles détaillées](../../guide/sandbox-sessions/).
