## Import

```ts
import { createFirecrackerSandboxProvider } from "@elie-laloum/outpost/providers/firecracker";
```

## Rôle et comportement

Crée un provider distant qui démarre une microVM Firecracker à partir de votre noyau, de votre système de fichiers racine et de votre périphérique TAP, puis joint l’invité par SSH. Il exige Linux avec /dev/kvm et un invité avec Node.js 24+, git, setsid et tar. Un provider exécute une VM à la fois ; release l’arrête et supprime sa copie privée du rootfs.

[Exemple complet et règles détaillées](../../guide/firecracker/).

| `options.root`           | `string \| undefined`                                                                                                                                                                                                               | Optionnel | Répertoire du dépôt dans l’invité, /workspace par défaut.                                                                                                                                                                                                                                                                                                                                                                                   |
| `options.home`           | `string`                                                                                                                                                                                                                            | Requis    | Home de l’agent dans l’invité ; il doit correspondre au HOME de l’utilisateur invité, sinon la vérification de démarrage n’aboutit jamais.                                                                                                                                                                                                                                                                                                  |
