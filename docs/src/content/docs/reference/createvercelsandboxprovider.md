## Import

```ts
import { createVercelSandboxProvider } from "@elie-laloum/outpost/providers/vercel";
```

## Purpose and behavior

Create a remote provider on Vercel Sandbox; the optional @vercel/sandbox SDK loads on acquire. Each acquire creates a sandbox, Outpost uploads the repository and synchronizes changes back, and release stops the sandbox.

[Complete example and detailed rules](../../guide/cloud-sandboxes/).
