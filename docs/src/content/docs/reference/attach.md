## Import

```ts
import { attach } from "@elie-laloum/outpost";
```

## Purpose and behavior

Open a CLI agent's own interactive terminal in a sandbox allocated for this call, then return the session's exit status and commits. Status 0 applies the branch policy and closes the sandbox; a nonzero status or a failure closes it and keeps the worktree. The agent process has a deadline of 86400000 (24 hours). Status 0 also checks the workspace diff guard before integration; a refused diff throws code guard and retains work.

[Complete example and detailed rules](../../guide/sandbox-sessions/).
