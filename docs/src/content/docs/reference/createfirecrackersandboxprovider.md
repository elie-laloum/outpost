## Import

```ts
import { createFirecrackerSandboxProvider } from "@elie-laloum/outpost/providers/firecracker";
```

## Purpose and behavior

Create a remote provider that boots a Firecracker microVM from your kernel, root filesystem and TAP device, and reaches the guest over SSH. It needs Linux with /dev/kvm and a guest with Node.js 24+, git, setsid and tar. One provider runs one VM at a time; release stops it and deletes its private rootfs copy.

[Complete example and detailed rules](../../guide/firecracker/).
