## Parameters and properties

The fields below cover all variants; the signature specifies their allowed combinations.

| Name                    | Type                                                                                                   | Presence          | Meaning                                                                                                                                                                                                                                                                                      |
| ----------------------- | ------------------------------------------------------------------------------------------------------ | ----------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `kind`                  | `"cli" \| "custom" \| "replay" \| "fallback"`                                                          | Required          | Execution discriminator: cli.                                                                                                                                                                                                                                                                |
| `harness`               | `CliHarness \| Harness`                                                                                | Variant-dependent | CLI preset the agent was composed with, such as createClaudeHarness() or createCodexHarness().                                                                                                                                                                                               |
| `model`                 | `AgentModel \| undefined \| AgentModel`                                                                | Variant-dependent | Normalized frozen AgentModel bound to the CLI command; absent when the native CLI default is kept.                                                                                                                                                                                           |
| `fork`                  | `((id: string, invoke: (command: Command) => Promise<CommandResult>) => Promise<string>) \| undefined` | Variant-dependent | Native fork preparation: receives the parent ID and a command executor on the borrowed sandbox, and returns a distinct child ID that Outpost then continues. Adapters with a fork flag can omit it.                                                                                          |
| `credentials`           | `((variables: Variables) => CredentialPlan) \| undefined`                                              | Variant-dependent | Plan the credentials of this CLI from the resolved workflow variables, without disk access: variables to forward, host files to copy into the private sandbox home, generated files and login commands. Called once per adapter and sandbox; the local provider receives only the variables. |
| `configuration`         | `((variables: Variables) => AgentConfiguration) \| undefined`                                          | Variant-dependent | Plan CLI configuration from the resolved variables, without disk access: files to merge and host files to copy into the agent home once per sandbox, after authentication. Throw when a referenced variable is missing.                                                                      |

| `events`                | `(line: string) => readonly AgentEvent[]`                                                              | Variant-dependent | Decode one native CLI output line into normalized agent events.                                                                                                                                                                                                                              |
| `quota`                 | `((text: string) => boolean) \| undefined`                                                             | Variant-dependent | Recognize a terminal usage-limit or rate-limit message in a failure event or stderr line. When the process then fails, the turn rejects with OutpostError code quota instead of process; transient retry notices must not match.                                                             |
| `unavailable`           | `((text: string) => boolean) \| undefined`                                                             | Variant-dependent | Recognize a terminal service outage or connection failure in a failure event or stderr line. When the process then fails without a quota signal, the turn keeps code process and records details.unavailable, read by unavailableFault(); retry notices must not match.                      |
| `usageCommand`          | `((conversation: string) => Command \| undefined) \| undefined`                                        | Variant-dependent | Build a bounded read-only command to collect counters for this conversation inside the borrowed sandbox; return undefined for an unsupported identifier.                                                                                                                                     |

| `name`                  | `string`                                                                                               | Variant-dependent | Native agent identifier used in execution events and diagnostics.                                                                                                                                                                                                                            |
| `bootstrap`             | `string \| undefined`                                                                                  | Variant-dependent | Built-in agent whose pinned CLI Outpost installs on a remote sandbox when the executable is missing: an npm package, or a SHA-512-verified archive for antigravity. An unknown name fails.                                                                                                   |
| `requiresFinishedEvent` | `boolean \| undefined`                                                                                 | Variant-dependent | Require the native final event: without it, completion markers do not match and the turn fails with code process, even when the process exits with 0.                                                                                                                                        |
| `usage`                 | `"events" \| "session" \| "unavailable" \| undefined`                                                  | Variant-dependent | How token usage is measured: events reads it from the output stream, session reads the session after the process exits, unavailable records none. | `variables`             | `Readonly<Record<string, string>> \| undefined`                                                        | Variant-dependent | Environment variables added to every command of this agent, over the values from .outpost/.env. A name also set by the sandbox provider fails with code configuration.                                                                                                                       |
| `storage`               | `ConversationStore \| undefined`                                                                       | Variant-dependent | Conversation store that captures, locates and restores this agent’s sessions; absent when its conversations are not portable.                                                                                                                                                                |
| `capture`               | `boolean \| undefined \| boolean \| boolean \| undefined`                                              | Variant-dependent | Save the conversation to storage after each turn; false skips it. | `resumable`             | `boolean \| undefined \| boolean \| boolean \| undefined`                                              | Variant-dependent | Whether the agent can continue a conversation, as continuation, response repairs and resume-based steering require; false rejects continuation before allocation. | `turns`                 | `readonly ReplayTurn[]`                                                                                | Variant-dependent | Recorded turns parsed from the journal, in execution order.                                                                                                                                                                                                                                  |
| `remainingTurns`        | `number`                                                                                               | Variant-dependent | Number of recorded turns not yet consumed by a dispatch; 0 after a complete replay.                                                                                                                                                                                                          |
| `nextTurn`              | `() => ReplayTurn \| undefined`                                                                        | Variant-dependent | Consume and return the next recorded turn, or undefined when the journal is exhausted. | `pendingSteering`       | `() => readonly string[] \| undefined`                                                                 | Variant-dependent | Recorded instructions that resumed the next turn, without consuming it; dispatch uses them to continue a steered pass as recorded. Undefined when the next turn was not a steering resumption.                                                                                               |
| `agents`                | `readonly Agent[]`                                                                                     | Variant-dependent | Candidates of a fallback agent, in the order they are tried.                                                                                                                                                                                                                                 |
| `on`                    | `readonly FallbackTrigger[]`                                                                           | Variant-dependent | Failure categories, quota or unavailable, that hand a fallback agent’s dispatch to its next candidate.                                                                                                                                                                                       |
