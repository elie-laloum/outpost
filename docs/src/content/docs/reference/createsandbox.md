## Import

```ts
import { createSandbox } from "@elie-laloum/outpost";
```

## Purpose and behavior

Allocate an environment with sandboxProvider and keep it open for sequential dispatches, commands and terminal sessions until you close it. Without workspace, it opens one that close() also closes, by default on the checkout in the current directory with Docker. If setup fails, it releases what it allocated, closes the workspace it opened and rethrows.

[Complete example and detailed rules](../../guide/sandbox-sessions/).
