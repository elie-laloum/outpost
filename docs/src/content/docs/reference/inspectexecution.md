## Import

```ts
import { inspectExecution } from "@elie-laloum/outpost/core";
```

## Purpose and behavior

Plans an execution from sandbox options without allocating, uploading files or starting an agent. For file workspaces it reports the binding the source needs, what the sandbox provider offers, each agent's declared file features, the requirements of the optional dispatch settings and every incompatibility; createSandbox() and dispatch() refuse the first diagnostic with the same message. Git options return the sandbox and agents with no file requirements. Extension providers are read from their runtime capabilities.

[Complete example and detailed rules](../../guide/sandbox-sessions/).
