title: "Learn Outpost"
description: "A progressive path from your first agent to durable workflows."
---

Follow this path in order, or open any practical page independently. Its preparation recreates everything the example needs.

1. [Start an agent](start/quickstart/): choose access, run the CLI starter and inspect its result.
2. [Understand the generated code](start/generated-script/): identify the repository, agent, provider and brief.
3. [Control the task](agents/dispatch/): prompts, validated responses, progress and conversations.
4. [Own the environment](environment/lifecycle/): sandbox lifetime, workspaces, Git and commands.
5. [Compose a workflow](workflows/graph/): typed results, dependencies and failure policies.
6. [Keep state](advanced/checkpoints/): persistence, decisions, artifacts and workers.
7. [Combine the pieces](cookbook/): complete recipes for real work.
8. [Recover deliberately](operations/troubleshooting/): diagnostics and retained work.

The [Reference](../reference/diagnosesandbox/) contains exhaustive contracts, options and compatibility details. You do not need to read it from beginning to end.
