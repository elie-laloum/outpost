## Validation

Local validation on Linux with Node.js 24.21.0 and Bun 1.3.14 covers the full working tree, including earlier audit batches:

- Architecture, build and TypeScript checks passed. Recipe parity covers 687 contracts; 100 native option contracts and the editor schemas are synchronized.
- The complete unit/functional suite passed with coverage: 1,383 passed, zero failures, one macOS-only test skipped. Coverage is 95.86% lines, 90.68% branches and 93.96% functions; all enforced thresholds passed.
- Real Docker: 31 suite tests passed, plus the new host-interruption regression. Real Podman: 32 cases validated across the full run (31 passed, one fixture timeout) and the successful isolated rerun. Both real PTY fixtures passed input, nonzero exit, cancellation and warm reuse.
- Standalone Redis: all 16 tests passed; a targeted rerun also verified compatibility with legacy serialized requests.
- Packed-package consumption passed. Documentation source checks, the static build, 2,639 rendered pages, 1,002 TypeScript snippets and 68 executed bilingual examples passed. All 140 browser cases passed across the initial run and the schema recheck after rebuilding the generated assets.
- Prettier checks on changed files and `git diff --check` passed.

The first Podman interruption check exceeded its 20-second fixture deadline during high host load; its isolated rerun passed. The new command-before-container shutdown regression passed on both engines.

Additional live validation on October 16, 2026 used private Docker sandboxes:

- OpenAI Responses and Anthropic model harnesses passed delegation, file editing, test execution, commit creation, continuation and warm reuse. Each successful run made ten model requests and completed cleanup. Responses transcripts contained portable encrypted reasoning. The project-local OpenAI credential was rejected; the successful run used the separately configured environment credential.
- Claude and Codex account authentication, conversation capture and native continuation passed. Both also acknowledged live steering and returned the steered response. Codex usage authentication passed in an isolated home.
- Antigravity account authentication and continuation in the same sandbox passed; this does not establish portable capture or fork support.
- The installed Kimi CLI passed the native fork fixture. Authenticated model execution remains unvalidated because no usable Kimi account profile was available.
- Copilot's live turn failed with a process error. Its cause remains unresolved; this is not a successful authenticated validation.
- Daytona and Vercel rejected the configured credentials before allocation. Elevated cancellation, cloud cache behavior and staged environment transfer still require live checks with valid access.
- Native macOS/Windows execution and a real Firecracker VM remain unvalidated. No test hosts or existing Firecracker configuration were available. Local KVM access alone does not validate the Firecracker provider or jailer.

Successful native runs completed sandbox cleanup. Cloud SDK fixtures and simulated SSH regressions do not replace outstanding live checks. These changes shipped in 11.2.0; the live checks above remain outstanding.
